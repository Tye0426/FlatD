01 / MODEL

模型参数

以下参数为默认值，用户可自行修改，并会用于后续求解。

TIME

全过程时间模型

T = Σ(T梯线 + T进入 + T退出)
Σ全部基本作业累计T梯线股道间转线走行T进入 / T退出车辆进出股道时间

每次牵出或推送均计算三个阶段并逐步累计。结果是模型估计耗时。

FORMULA

单步走行时间

T梯线 = |k旧−k新| × 股道间距 / 梯线速度T阶段 = lk/sm + 0.5sm(a + bn)

未计防溜、制动试验与现场等待。

SPEED

运行参数

A*

搜索优先级

η = T + wΛ

T为累计模型时间，Λ为deferred link数量；350是算例参数，不一定是所有任务的统一最优值。

SAN

SAN目标

max R = Σ rijxij
rij弧 i→j 的奖励xij∈{0,1}是否选取该弧R本轮SAN子问题的总奖励

SAN奖励负责筛选候选动作；最终完整方案仍按累计总时间判断优劣。

REWARD

SAN弧奖励

Virtual 1继续采用默认长度修正式 1/(2lₖ)。
